# VYDEX: RED FRONTIER

The existing four-mission game now includes a **three-vehicle 3D launch catalogue** connected to assembly, preflight and the actual cinematic launch model.

**Flow:** Destination → objective → rocket → spacecraft workshop → preflight → launch → planned travel → local operations → acknowledged science → debrief.

## Run locally

```sh
npm install
npm run dev
```

Production:

```sh
npm test
npm run build
npm run preview
```

Open the URL printed by Vite (normally http://localhost:5173 for development or http://localhost:4173 for preview). PWA installation and offline caching require the production build on localhost or HTTPS. Downloadable build ZIP includes RUN_GAME.txt for serving without Node.

## New launch-vehicle catalogue

Vehicles are real NASA launchers (Atlas V 401, Atlas V 541, SLS Block 1) with public dimensions and thrust; credit costs and delivery capacities are **scaled game values**.

Titan has two serial stages and a paired booster stage group. The service includes provider fuel and destination injection. Provider mass/fuel never enters spacecraft mass or spacecraft tanks. Titan retains the old 10-credit / 1200 kg Mars service, so existing Mars starter designs and budget remain valid.

Select any rocket to orbit/zoom its actual model; card images are generated by the shared WebGL renderer from those same meshes. Every specification has an explicit information button. Switching service preserves assembled parts. Preflight independently checks route support, wet mass, conservative stowed cylindrical fit and budget. The workshop shows the chosen fairing envelope; fuel fill affects mass but not hardware dimensions.

## Assembly and inspection

Sixteen meaningful physical assemblies include tanks, structure, cruise stage/engine, navigation, electrical, communications, landing, rover and science hardware. Category filters and local model thumbnails organize the library. Navigation includes sensors/reaction wheels; cruise engine includes RCS; antenna includes its transmitter; rover includes wheels and motors. These are stated assemblies, not extra invisible purchasable hardware. Launch fairing belongs to the provider service.

Click or drag parts onto compatible mounts. ⓘ explains purpose, numbers, mounting, trade-offs, omission and beginner examples, with underlying science links. Front/side/rear/engine presets, orbit/zoom, labels, exploded view and Reset camera support close inspection. Flight inspection pauses local simulation and preserves the craft when resumed.

## Controls

- **Launch:** complete the checklist; Follow / Cinematic / Overview, distance, time acceleration, pause, cutaway and authorized skip are presentation controls. Ascent is explicitly scripted.
- **Transfer:** choose a power profile and execute the planned correction burn. Free arcade thrust is disabled here; Mars keeps the calculated ideal Hohmann route.
- **Local flight:** W/S pitch, A/D yaw, Q/E roll, Shift/Ctrl throttle, X engine cutoff, C camera, Space stabilization. Asteroid arrows translate with RCS. Ignition/shutdown buttons and touch attitude buttons duplicate keyboard actions. Earth deployment controls attitude only, preserving its reference circular orbit.
- **Landing:** pitch/roll tilt thrust, yaw changes heading. Assist computes braking; throttle trims it. Shutdown overrides assist. Moon uses zero atmospheric drag; Mars retains its exponential approximation.
- **Rover:** WASD/arrows drive, Space brake, E interact, C camera; instrument buttons photograph/analyze/drill suitable nearby sites. Minimap shows landing site, targets, rover and storage. Command queue previews approximate gross electrical requirements, drives and observes autonomously; transmission is explicit. Recovery is labeled game assistance.
- **Esc:** pause; Controls menu, tutorial replay, save/load, mute/volume and graphics quality.

Telemetry labels reference frames and explains mass, throttle, energy and compression with ⓘ. Local attitude, RCS and main-engine inputs consume actual propellant; no atmospheric smoke appears in vacuum. Exterior engine sound is cinematic sonification.
